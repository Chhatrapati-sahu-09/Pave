## About

Pave is a full-stack web application that enables users to report accessibility barriers such as:

- Broken sidewalks
- Missing curb ramps
- Blocked pathways
- Stairs without ramps
- Dangerous steep grades

The platform helps wheelchair users, parents with strollers, elderly people, and anyone who depends on accessible routes by building a real-time, crowdsourced accessibility map.

---

## Features

- Interactive Mapbox map
- Report accessibility issues
- Photo uploads
- Heatmap visualization
- Clustered pin view
- Community confirmations and disputes
- Severity-based color coding
- Browser geolocation
- Secure authentication
- PostGIS spatial filtering
- Responsive design
- Neo-Brutalist UI
